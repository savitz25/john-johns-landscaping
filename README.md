# John Johns Landscaping

Modern single-page website for **John Johns Landscaping** — a local landscaping company based in **Cliffwood, New Jersey**.

## Live preview

Open `index.html` in a browser, or serve locally:

```bash
# Python
python -m http.server 8080

# Node
npx serve .
```

Then visit `http://localhost:8080`.

## Features

- Fixed navigation with mobile menu
- Full-screen hero with landscaping photography
- Services, pricing (Standard $150 / Premium $185), about, and contact sections
- Responsive layout (desktop → mobile)
- Forest green design system with Playfair Display + Inter
- Smooth scroll, hover animations, and scroll reveal

## Stack

Static HTML, CSS, and JavaScript — no build step required. Ready for GitHub Pages or any static host.
